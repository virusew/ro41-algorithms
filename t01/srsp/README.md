# СРСП 1. Перевод секунд

1. Прочитать общее число секунд.
2. При нецелом или отрицательном вводе вывести ошибку и закончить.
3. Целым делением на 3600 найти часы, затем вычислить остаток секунд.
4. Целым делением остатка на 60 найти минуты. Остаток от деления на 60 даёт секунды.
5. Вывести часы, минуты и секунды.

```text
ввод total
если total не целое или total < 0:
    вывод сообщения об ошибке
    завершить
h := total div 3600
rest := total mod 3600
m := rest div 60
s := rest mod 60
вывод h, m, s
```

| Ввод | Ожидалось | Получено |
|---|---|---|
| 3725 | 1 ч 2 мин 5 с | 1 ч 2 мин 5 с |
| 59 | 0 ч 0 мин 59 с | 0 ч 0 мин 59 с |
| 86399 | 23 ч 59 мин 59 с | 23 ч 59 мин 59 с |
| 0 | 0 ч 0 мин 0 с | 0 ч 0 мин 0 с |
| abc | Сообщение об ошибке | Сообщение об ошибке |
| -1 | Сообщение об ошибке | Сообщение об ошибке |
