# СРС 8. Трассировка методов string и StringBuilder

## 1. Trim и Split

Исходная строка: `" Ахметов Ерлан;85 "`. После `Trim()`: `"Ахметов Ерлан;85"`.

| Индекс после Split(';') | Элемент | Длина |
|---:|---|---:|
| 0 | `"Ахметов Ерлан"` | 13 |
| 1 | `"85"` | 2 |

## 2. TryParse

После `"Иванов Пётр;70;85;x".Split(';')` проверяем части с индексами от 1. Часть 0 содержит имя.

| Индекс | Часть | Результат int.TryParse | Значение out |
|---:|---|---|---:|
| 1 | `"70"` | true | 70 |
| 2 | `"85"` | true | 85 |
| 3 | `"x"` | false | 0 |

`TryParseScores` вернёт **false**, поскольку `x` нельзя преобразовать в целое число. Имя служит отдельным полем.

## 3. Конкатенация и StringBuilder

| i | s после s += i | Строка-результат конкатенации | Содержимое sb после Append(i) | Новых строк-результатов Append |
|---:|---|---|---|---:|
| 0 | `"0"` | Готовая строка числа | `0` | 0 |
| 1 | `"01"` | Новый объект | `01` | 0 |
| 2 | `"012"` | Новый объект | `012` | 0 |
| 3 | `"0123"` | Новый объект | `0123` | 0 |

Получаем четыре последовательных строковых результата. При сложении с пустой строкой .NET может вернуть уже имеющуюся строку числа; для трёх остальных результатов нужны отдельные объекты. Строковые представления самих чисел зависят от реализации и кэша. В учебном подсчёте по значениям `s` получается 4 результата против 0 при `Append(int)`. У `StringBuilder` создаётся один объект построителя, а итоговая строка выделяется при `sb.ToString()`.

## 4. ToUpper

Строки в C# неизменяемы. Вызов `s.ToUpper()` возвращает результат, а переменная `s` сохраняет прежнее значение. Чтобы сохранить результат, нужно написать `s = s.ToUpper();`.
