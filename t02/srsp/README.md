# СРСП 2. Количество и сумма цифр

```text
ввод n
если n не целое или n < 0:
    вывод сообщения об ошибке
    завершить
sum := 0
count := 0
повторять
    sum := sum + (n mod 10)
    count := count + 1
    n := n div 10
пока n > 0
вывод count, sum
```

Цикл с проверкой в конце выполняется хотя бы один раз. Для нуля получаем одну цифру и сумму 0.

| Вход | Итерация | n | Сумма | Количество | n > 0 после шага |
|---:|---|---:|---:|---:|---|
| 472 | До цикла | 472 | 0 | 0 | Ещё не проверяется |
| 472 | 1 | 47 | 2 | 1 | Да |
| 472 | 2 | 4 | 9 | 2 | Да |
| 472 | 3 | 0 | 13 | 3 | Нет |
| 0 | До цикла | 0 | 0 | 0 | Ещё не проверяется |
| 0 | 1 | 0 | 0 | 1 | Нет |

| Ввод | Ожидалось (количество, сумма) | Получено |
|---|---|---|
| 472 | 3, 13 | 3, 13 |
| 0 | 1, 0 | 1, 0 |
| 7 | 1, 7 | 1, 7 |
| 1000 | 4, 1 | 4, 1 |
