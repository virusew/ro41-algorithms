# СРСП 4. Статистика оценок

Оценки вводятся по одной на строку. Ноль завершает ввод. Нечисловые строки и числа вне диапазона 2–5 пропускаются.

| Ввод | Ожидалось | Получено |
|---|---|---|
| 5, 4, 5, 0 | 3 оценки, средний балл 4,67, 2 пятёрки | 3 оценки, средний балл 4,67, 2 пятёрки |
| 0 | Оценок нет | Оценок нет |
| 3, 7, abc, 2, 0 | 2 оценки, средний балл 2,50, 0 пятёрок | 2 оценки, средний балл 2,50, 0 пятёрок |

Разделитель дробной части в консоли зависит от региональных настроек.
